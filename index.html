주문·견적 포털 화면

제안한 서비스의 핵심 흐름을 담은 42개 화면을 직접 조작해 보실 수 있습니다. 실제 업무 흐름에 가깝게 구성했으며, 거래처·상품·단가·주문 정보는 모두 가상의 예시입니다.

  • 처음에는 로그인 화면이 열립니다. 「접속 계정 안내」를 펼친 뒤 계정을 선택하면 바로 접속됩니다. 등급이 다른 거래처와 권한이 다른 관리자 화면을 각각 확인할 수 있습니다
  • 거래처용 24개 화면, 관리자용 18개 화면을 단말 너비에 맞춰 재배치되는 반응형 UI로 구성했습니다
  • 공급가는 기본가 → 등급 할인 → 거래처 개별 단가 순으로 적용되며, 로그인한 거래처의 가격만 조회됩니다
  • 주문·견적이 확정되는 시점의 단가와 금액을 보관하므로, 이후 기준 단가를 바꿔도 기존 주문 금액은 변하지 않습니다
  • 최소 주문 수량과 주문 단위는 담기 · 주문서 작성 · 최종 확정 세 지점에서 각각 확인합니다

서비스 화면에 표시되는 거래처·상품·단가 정보는 모두 가상의 예시입니다.

「한성상사」와 거래처, 상품·공급가·주문·견적 내역은 시연을 위해 만든 가상의 자료이며 실제 정보가 아닙니다. 기준 시각은 2026-09-29로 고정해 언제 열어도 같은 화면이 보이도록 했습니다. 화면에서 변경한 값은 현재 브라우저 메모리에만 보관되며 새로 고치면 초기 상태로 돌아갑니다. 여러 사용자가 같은 주소에 동시에 접속해도 각자의 화면은 서로 영향을 주지 않습니다. 결제·메일 발송·파일 내려받기는 화면 흐름만 재현하며 실제로 처리되지 않습니다. 해시 기반 주소를 사용하므로 .../prototype/#/a/prices처럼 화면 주소를 그대로 전달하실 수 있습니다.

화면에 보이는 기능이 모두 1차 범위에 포함되는 것은 아닙니다.

정확한 개발 범위는 웹 제안서를 기준으로 확인해 주세요. 다음 네 가지는 1차 범위에 포함되지 않는 별도 견적 대상입니다: 가상계좌 발급·자동 입금 확인(A), 카카오 알림톡 발송(B), 후불 거래처 외상 한도·미수금 관리(C), 기존 자료 이관 대행(D). ERP·물류·회계 연동, 전자세금계산서 발행, 사업자등록번호 자동 진위 확인, 택배사 실시간 배송 추적, 모바일 앱, 다국어·해외 결제도 1차 범위 밖입니다. 화면에 보이는 등급 체계·할인율·견적 유효기간 정책은 협의 전 가정값이며, 착수 1주차 승인 단계에서 확정합니다. 각 항목의 근거는 웹 제안서 「기간·예산」·「개발 범위」 섹션에 있습니다.
