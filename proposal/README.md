# 웹 제안서 — B2B 전용 주문·견적 쇼핑몰 자체 구축

위시켓 158766 제안서(`../제안서.md`)의 웹 버전입니다. 빌드 과정과 외부 프레임워크 없이
`index.html` + `assets/style.css` + `assets/app.js` 세 파일로 동작합니다.

## 파일 구성

```
proposal/
├─ index.html          웹 제안서 본문 (단일 페이지, 9개 섹션)
├─ .nojekyll           GitHub Pages 에서 Jekyll 처리를 끈다
├─ README.md           이 파일
└─ assets/
   ├─ style.css        스타일.md 「레드」 가이드 §13 웹 제안서 규격 구현
   ├─ app.js           스크롤 리빌 · 카운터 · 간트 · 탭 · 테마 · 인쇄 (외부 의존성 없음)
   └─ favicon.svg
```

외부 요청은 Pretendard 웹폰트(cdn.jsdelivr.net) **한 건뿐**이며, 차단되어도
나눔고딕·맑은 고딕 대체 스택으로 정상 렌더됩니다.

## 기능

- **다크 모드 3상태** — 시스템 → 라이트 → 다크 순환, `localStorage` 저장 (try/catch)
- **스크롤 리빌 · 숫자 카운터 · 바 성장 · 간트 순차** — `prefers-reduced-motion` 에서 전부 확정 상태로 정지
- **탭 8개** (견적 3 + 개발 범위 5) — 키보드 좌우 이동 지원, 인쇄 시 전부 전개
- **인쇄** — 상단 바 버튼 또는 브라우저 인쇄. A4 24페이지, 다크로 인쇄되지 않음
- **JS 미실행 상태에서도** 모든 수치가 최종값으로 표시됨

## 검증

```
python3 verify_web.py    # 제안서.md ↔ index.html 내용 대조 460건
node    t_check.js       # 브라우저 5종 뷰포트 + 모션축소 + 인쇄 88건
```

`verify_web.py` 는 기대값을 하드코딩하지 않고 **제안서.md 의 표를 파싱해** 웹과 대조합니다.
제안서를 고치면 이 스크립트가 불일치를 잡아냅니다.
